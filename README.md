# MediGuard-AI

### Secure Medical Wireless Sensor Network with AI-Based Anomaly Detection

## About the Project
MediGuard-AI is a Medical Wireless Sensor Network (MWSN) simulation project that combines wireless sensor networks and artificial intelligence to detect abnormal behavior.

## Objectives
- Simulate a Medical Wireless Sensor Network.
- Monitor medical sensor data.
- Detect anomalies using AI techniques.
- Improve network monitoring and security.

## Technologies
- Artificial Intelligence
- Wireless Sensor Networks
- Network Simulation
